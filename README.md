# DocGen AI — AI Technical Documentation Generator

A web app that turns source code into technical documentation. Paste code, upload files/zip archives, or import a
public GitHub repository, choose a document type, and get rendered Markdown streamed back in real time.

## Features

- **Inputs:** paste code, drag-and-drop files or `.zip` archives, or import a public GitHub repo (optionally a branch/subfolder via `/tree/<branch>/<path>`).
- **Document types:** README, API Reference, Architecture Overview (with Mermaid diagrams), Inline Docstrings, Developer Onboarding Guide, or Custom instructions.
- **Options:** audience (developers / beginners / stakeholders), detail level, output language, extra instructions.
- **AI providers:** OpenAI and any OpenAI-compatible API (Groq, OpenRouter, Together, Ollama, LM Studio…), Anthropic Claude, Google Gemini — streamed token by token.
- **Offline mode:** no API key needed — documentation is generated by static analysis (Python AST; regex parsers for JS/TS, Go, Java, Rust, Ruby, PHP, C#, Kotlin, C/C++), including endpoint detection, dependency graphs and docstring stubs.
- **Output:** live Markdown preview with syntax highlighting and Mermaid diagrams, editable raw Markdown, copy, download `.md`, export HTML, local history, light/dark theme.

## Quick start

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
# open http://localhost:8000
```

Or with Docker:

```bash
docker build -t docgen-ai .
docker run -p 8000:8000 -e OPENAI_API_KEY=sk-... docgen-ai
```

## Configuration

API keys can be entered per-user in the app's **Settings** dialog (stored only in the browser's localStorage), or set
server-side via environment variables (see `.env.example`):

| Variable | Description |
|---|---|
| `LLM_PROVIDER` | Default provider: `openai`, `anthropic`, `gemini` or `offline` |
| `LLM_MODEL` | Default model for the default provider |
| `LLM_BASE_URL` | Base URL for OpenAI-compatible APIs (default `https://api.openai.com/v1`) |
| `OPENAI_API_KEY` / `ANTHROPIC_API_KEY` / `GEMINI_API_KEY` | Server-side provider keys |
| `GITHUB_TOKEN` | Optional, raises GitHub rate limits for repo imports |

If no provider key is configured, the app defaults to Offline mode.

## API

| Method | Path | Description |
|---|---|---|
| `GET` | `/api/config` | Document types, providers and which have server-side keys |
| `POST` | `/api/ingest` | Multipart `files[]` and/or `github_url`; returns extracted source files |
| `POST` | `/api/generate` | JSON body with `files`, `doc_type`, options and provider settings; streams Server-Sent Events (`meta`, `chunk`, `error`, `done`) |
| `GET` | `/api/health` | Health check |

## Project structure

```
app/
  main.py      FastAPI routes and SSE streaming
  llm.py       Streaming clients for OpenAI-compatible, Anthropic and Gemini APIs
  prompts.py   Prompt templates per document type
  ingest.py    File/zip/GitHub ingestion, filtering and prompt bundling
  analyzer.py  Offline static-analysis documentation generator
static/        Single-page frontend (HTML/CSS/vanilla JS)
tests/         Pytest suite
```
